**🏋️ GymTracker** — *Training platform for gyms · Available on Google Play*

Independent project built by a 2-developer team. I built the Angular frontend from scratch and integrated it with the Spring Boot REST API:

- One codebase for the web panel (superadmin, gym admin, coach) and the athletes' Android app via **Capacitor**
- **JWT** authentication with automatic session renewal through typed API clients and HTTP interceptors
- **Offline mode**: cached data loads instantly and workouts logged offline sync when the connection returns
- Push notifications (FCM) and **91 Vitest test files**
